# 紙匣

<img src="icon.svg" alt="紙匣" width="96">

PDF 與圖片的隨手工具，在瀏覽器裡處理，檔案不會上傳到任何伺服器。函式庫已放在 `lib/`，桌面版不需要網路。

## 功能

- **合併**：多份 PDF 接成一份，可拖曳排序，每份可只取部分頁面（如 `1-3, 5`）；也可以放入圖片，每張變成一頁 A4（例如申請表加上證件照片）。「交錯：雙面掃描」把只能單面掃描的事務機掃出的正面檔和反面檔排回 正1、反1、正2、反2…（反面整疊翻過來掃、頁序倒過來的情況預設會自動倒回；兩份頁數不同會提醒）
- **拆分**：依頁碼範圍（如 `1-3, 5, 8-`）、每 N 頁或每頁一份，多份打包成 ZIP
- **編輯**：排序、旋轉、刪除、複製頁面、插入空白頁、其他 PDF 或圖片、加文字與簽名、只匯出選取頁；可復原／重做（Ctrl+Z／Ctrl+Y）；按住 Shift 連續勾選；「選取空白頁」自動勾選沒有內容的頁面（例如雙面掃描時空白的背面，灰底、雜點和背面透過來的淡字都不算內容），確認後再刪除；快捷鍵 Delete 刪除、R 旋轉、D 複製、← → 移動、Ctrl+A 全選、Esc 取消選取
- **頁碼與頁首頁尾**（編輯分頁下方）：頁碼格式（`1 / 10`、`第 1 頁，共 10 頁`、`- 1 -` 等）、位置、起始數字、封面不編號；頁首頁尾文字可用 `{頁}`、`{總頁}`、`{日期}`、`{檔名}`，中文也可以
- **文件資訊**（編輯分頁下方）：標題、作者、主旨、關鍵字，放入檔案時帶入原本的值；可選擇不記錄建立程式與日期
- **填表單**：可填寫的 PDF（AcroForm）直接在欄位上打字、勾選、下拉選擇；中文會以清晰的圖片寫進欄位外觀，任何閱讀器都看得到；可選擇「壓平」讓內容無法再修改。XFA 動態表單不支援
- **標註**：在頁面上畫螢光筆、方框、箭頭、手繪線條，可改顏色與粗細
- **簽名**：手寫或上傳簽名（白底自動去背），放到頁面上可拖曳縮放，可一次套用到所有頁、奇偶頁或指定頁；一鍵在簽名旁加上今天日期（西元或民國格式）；簽名只存在本機瀏覽器
- **遮蔽個資**：框選要遮住的範圍，或「自動尋找」身分證／居留證號、手機、市話、Email、信用卡號、日期與自訂關鍵字，一次在所有頁面加上遮蔽框（掃描檔會先用 OCR 辨識文字，結果會留著，再找一次不用重新辨識）；匯出時有遮蔽的頁面整頁轉成圖片，黑框下的文字與圖片真正刪除；其他頁面不受影響
- **加浮水印**：文字或圖片，可選位置（置中／平鋪／四角）、角度、透明度、套用頁面，即時預覽
- **調整尺寸**：把頁面統一成 A4／A3／A5／B5／Letter／Legal（內容保持向量），或自動裁掉白邊
- **壓縮**：可一次放入多份；照片在背景用多個核心同時處理；「保留文字」只重新壓縮照片，文字仍可選取；「整頁轉成圖片」適合掃描檔；輕度／標準／強力三種強度；色彩可選彩色、灰階或黑白（黑白最適合文字掃描檔，每頁通常只要幾 KB 到幾十 KB）；沒有變小的檔案保留原檔；可設定**大小上限**（如 2 MB 以下，或自訂），會自動試壓幾次，找出不超過上限、畫質最好的設定，壓不到時會說明可以怎麼辦
- **密碼**：解除 PDF 的開啟密碼（銀行、信用卡、電信的電子帳單常用身分證字號或生日），或只有列印／複製限制的檔案直接解除；也可以幫 PDF 加上開啟密碼（AES-256）和「不能列印／複製／修改」的限制。用 qpdf 處理，檔案內容不重畫、完全不變；加密後會先驗證「要密碼才能開、密碼正確能開」才交出檔案。有密碼的檔案放進其他工具時會提示先到這裡解除
- **圖片轉 PDF**：JPG、PNG、WebP、HEIC（iPhone 照片）合成 PDF，可選 A4／Letter／原圖大小、方向與邊界
- **校正翻拍的文件**（圖片轉 PDF 每張的「校正」）：自動找出紙張四個角（可手動拖曳），拉正透視、去陰影、紙張變白，可選灰階或黑白，可旋轉；隨時可還原原圖
- **證件影印**：身分證、健保卡、駕照、居留證或護照資料頁的正反面照片，自動找出證件邊緣裁切拉正（可手動「校正」調整四個角、旋轉），依實際大小（或放大 150%／200%）排在同一張 A4，上下或左右排列，彩色或灰階；可加「僅供 ○○ 使用」之類的註記文字壓在證件上，防止影本被挪用（註記會記住，下次不用重打）
- **證件照**：一張大頭照裁成 2 吋（3.5×4.5 cm）、1 吋（2.8×3.5 cm）、美國簽證（5.1×5.1 cm）或自訂尺寸，拖曳／縮放／扶正／調亮度，有「頭頂」「下巴」參考線（2 吋依頭頂到下巴 3.2–3.6 cm）；排滿一張 4×6 相紙（2 吋 8 張、1 吋 12 張，300 dpi JPG，可拿到超商或相館沖印）或 A4 PDF，可印出裁切線
- **PDF 轉圖片**：每頁存成 JPG 或 PNG（72／150／300 dpi），多頁打包成 ZIP；格式選「文字 TXT」則抽出選取頁面的文字，可在預覽直接複製或存成 .txt（沒有文字的掃描頁會用 OCR 辨識，可取消勾選）。部分字型會把「日」「長」等字存成外觀相同的部首字元，抽出時會轉回正常的字，搜尋與遮蔽個資的關鍵字比對也一樣
- **文字辨識（OCR）**：掃描的 PDF 或照片（可多張）辨識出繁體中文和英文，做成可以搜尋、選取、複製文字的 PDF（頁面完全不變，只加上看不見的文字；中文詞之間不會多出空格，搜尋「管理委員會」找得到），或存成 .txt；預設只辨識沒有文字的頁面。在瀏覽器裡用 Tesseract 辨識，第一次使用載入約 8 MB，一頁約 5–20 秒。需要用本機伺服器開啟（見下方「使用方式」）
- **比較**：放入舊版和新版兩份 PDF，找出改過的文字：清單列出每一處修改／刪除／新增，兩份並排顯示，刪掉的字標紅、新增的字標綠，點清單或標記兩邊一起跳到那裡（← → 換下一處）。換行、空格和全形／半形不算差異；先比對行再比對字，內容只是換行或移到下一頁不會被當成修改。掃描檔可以先用 OCR 辨識再比較。只比較文字，不比較圖片與排版
- **圖片工具**：壓縮、限制尺寸、轉成 JPG／PNG／WebP，可多張一起處理
- **去浮水印**：筆刷塗抹後以內容感知填補（多尺度 PatchMatch，在背景 Worker 執行）；可放大、拖曳畫面

通用：
- **先預覽、不自動下載**：處理完會直接開啟結果預覽，滿意再按「下載」；畫面下方的結果列可以再次預覽或下載。想要完成就直接存檔，勾選右上角的「完成後自動下載」
- **Ctrl+V 貼上**：截圖、複製的圖片或在檔案總管複製的檔案，直接貼到目前的工具（等同拖曳進去）
- **HEIC**：iPhone 照片在圖片轉 PDF、圖片工具、去浮水印、合併、編輯都可以直接放入，會先轉成 JPG
- **工具間串接**：結果列上的「接著處理」可以直接把結果送到其他工具，不用先下載再上傳
- **可取消**：處理中的按鈕會顯示「取消」，再按一次就停止
- **手機拖曳排序**：長按縮圖或清單項目再拖曳
- **看大圖**：在編輯、拆分、PDF 轉圖片點縮圖可以放大檢視，← → 換頁
- **大檔案**：頁面縮圖只在捲到附近時才畫，數百頁的檔案也能馬上開始操作

## 使用方式

用 Chrome 或 Edge 開啟 `index.html`。

直接雙擊開啟時，瀏覽器不允許背景 Worker，PDF 解析會改在頁面上執行，大檔案會比較慢，**文字辨識（OCR）也無法使用**。想要最快的速度並使用全部功能，改用本機伺服器開啟：

```powershell
python -m http.server 8000
```

然後在瀏覽器打開 http://localhost:8000

## 檔案結構

```
紙匣/
├─ index.html           入口：頁面結構（各分頁的 HTML）＋載入 CSS／JS
├─ icon.svg             網站圖示（分頁 icon、頁首標誌）
├─ css/
│  └─ styles.css        全部樣式（顏色變數、深色模式、各工具版面）
├─ lib/                 第三方函式庫的本機副本（離線使用）
│  ├─ pdf-lib.min.js    pdf-lib 1.17.1：產生與修改 PDF
│  ├─ pdf.min.js        pdf.js 3.11.174：顯示與轉圖
│  ├─ pdf.worker.min.js pdf.js 的背景 Worker
│  ├─ jszip.min.js      JSZip 3.10.1：打包 ZIP
│  ├─ heic2any.min.js   heic2any 0.0.4：HEIC 轉 JPG（缺少這個檔時會改從 cdnjs 載入）
│  ├─ qpdf/             qpdf（@neslinesli93/qpdf-wasm 0.3.1）：解除／加上密碼；qpdf.wasm.js 是把 .wasm 轉成 base64 的 script，直接雙擊開啟也能載入
│  └─ tesseract/        Tesseract.js 7.0.0：文字辨識（約 8.5 MB）
│     ├─ tesseract.min.js、worker.min.js
│     ├─ tesseract-core-simd-lstm.wasm.js   辨識核心（tesseract.js-core 7.0.0，WebAssembly 已內嵌）
│     └─ lang/          繁體中文、英文的辨識資料（@tesseract.js-data 1.0.0 的 4.0.0_best_int）
├─ js/                  依載入順序：
│  ├─ core.js           共用：工具函式、存檔、可取消的工作、工具間串接、拖放與 Ctrl+V 貼上、HEIC 轉換、圖片轉 PDF 頁、拖曳排序、範例檔、縮圖、頁碼範圍、座標換算
│  ├─ samples.js        「合併」首頁的兩份範例檔（預先產生，開啟時不必載入函式庫）
│  ├─ inpaint.js        去浮水印的補圖演算法（會被包成 Web Worker）
│  ├─ preview.js        點縮圖放大檢視頁面
│  ├─ merge.js          合併（依序或雙面掃描交錯）
│  ├─ split.js          拆分
│  ├─ edit.js           編輯頁面、復原／重做、插入頁面、頁碼與頁首頁尾、文件資訊、匯出
│  ├─ editor-dialog.js  頁面編輯視窗：文字、簽名、標註、遮蔽，套用到多頁
│  ├─ signatures.js     簽名管理、手寫板、「簽名」分頁
│  ├─ redact.js         「遮蔽個資」分頁、自動尋找個資（遮蔽框在編輯視窗畫，匯出時在 edit.js 處理）
│  ├─ form.js           填寫 PDF 表單
│  ├─ watermark.js      加浮水印
│  ├─ resize.js         調整頁面尺寸、裁白邊
│  ├─ compress.js       壓縮（保留文字／整頁轉圖片）
│  ├─ img2pdf.js        圖片轉 PDF
│  ├─ scan.js           校正翻拍的文件（透視校正、去陰影、黑白）
│  ├─ idcard.js         證件影印（正反面排在同一張 A4、註記文字）
│  ├─ idphoto.js        證件照排版（裁切框與參考線、4×6／A4 排版、300 dpi 輸出）
│  ├─ pdf2img.js        PDF 轉圖片、抽出文字
│  ├─ ocr.js            文字辨識：Tesseract 引擎（載入、排隊、閒置一分鐘後關閉）、頁面文字與每個字的位置（遮蔽個資、比較共用）、可搜尋 PDF 的隱形文字層、「文字辨識」分頁
│  ├─ compare.js        比較兩份 PDF（Myers diff：先比行再比字）
│  ├─ password.js       解除／加上密碼（qpdf）
│  ├─ imgtool.js        圖片工具
│  ├─ unmark.js         去浮水印的介面
│  └─ app.js            分頁切換與啟動（最後載入）
├─ tools/
│  └─ build.py          打包成單一檔案
└─ dist/                build.py 的產出（不在版本控制內）
   ├─ 紙匣.html          單一檔案版，可直接寄給別人（函式庫改從 cdnjs 載入，需要網路）
   └─ artifact.html     發布到 Claude Artifact 用
```

函式庫（`lib/`）不在 `index.html` 裡載入，而是第一次用到時由 `js/core.js` 的 `LIBS` 動態載入。

JS 檔案是一般 `<script>`（不是 ES module），彼此共用最上層的變數與函式，所以 `index.html` 裡的載入順序不能亂改；這樣做是為了讓 `index.html` 直接雙擊開啟也能運作。

## 修改後

改完 `index.html`、`css/` 或 `js/` 之後，執行：

```powershell
python tools/build.py
```

會重新產生 `dist/` 裡的單一檔案版。線上版（https://claude.ai/artifact/LrA1FQYwq2f55Y6jAAwKY1）用 `dist/artifact.html` 發布。

更新 `lib/` 裡的函式庫版本時，也要一起修改 `tools/build.py` 的 `CDN` 對照表。Tesseract.js 不在 cdnjs 上，單一檔案版改從 jsdelivr 載入，辨識資料也是第一次使用時從網路下載（之後存在瀏覽器裡）。

## 記憶體

- 函式庫（pdf-lib、pdf.js、JSZip、Tesseract、qpdf）和背景處理（PDF 解析、去浮水印、照片壓縮、文字辨識）都在第一次用到時才載入或啟動；剛開啟時只佔約 1 MB。
- 文字辨識的背景程式會佔用超過 100 MB，閒置一分鐘後自動關閉，下次用到再啟動（本機檔案載入很快）。
- 切換分頁時，會釋放其他工具的 PDF 快取（已解碼的圖片、字型）；檔案仍保留，回來時重新讀取。
- 頁面縮圖存成 Blob，不佔 JavaScript 記憶體；換檔或清空時會釋放。
- 編輯、拆分、加浮水印只留一份檔案（在 PDF 解析器裡），匯出時才取回並解析；合併只在按下「合併」時解析一次。
- 用「接著處理」把結果交給下一個工具時，直接共用同一份資料，不另外複製。
- 去浮水印只有照片本身是原尺寸；筆刷遮罩最多 2000 px 寬，「按住看原圖」只在按住時才解碼。
- 處理過的檔案會留在記憶體裡直到換檔、清空或關閉分頁。切換分頁時，如果其他工具合計留著超過 50 MB，分頁列下方會出現提示，按「釋放記憶體」就清空那些工具（目前這個工具和正在處理中的工具不受影響）；按「不用」則要再多累積約 20 MB 才會再提示。每個工具用 `registerHolder()`（`js/core.js`）回報自己佔用的大小和清空的方法，新增工具時記得一起註冊。
