# 紙匣 Papertray

<img src="icon.svg" alt="" width="80" align="right">

**在瀏覽器裡處理 PDF 與圖片的隨手工具。檔案不會上傳到任何伺服器，可以離線使用。**

合併、拆分、編輯、簽名、填表單、遮蔽個資、文字辨識（OCR）、比較兩個版本、解除或加上密碼、壓縮、證件影印與證件照排版⋯⋯日常會遇到的 PDF 雜事，打開一個網頁就能做完。介面是繁體中文，也照顧到台灣常見的情況：身分證字號、民國日期、帳單密碼、2 吋照片、超商相片列印。

## 開始使用

| 方式 | 怎麼做 | 適合 |
|---|---|---|
| **線上版** | 打開 https://jyli0828.github.io/papertray/ ；網址列或頁首的「安裝」可以裝成 App | 大部分人；裝好後離線也能用，檔案一樣不會上傳 |
| 本機伺服器（建議） | 在專案資料夾執行 `python -m http.server 8000`，用 Chrome 或 Edge 打開 http://localhost:8000 | 日常使用，全部功能、速度最快、不需要網路 |
| 直接開啟 | 雙擊 `index.html` | 臨時用；大檔案較慢，**文字辨識無法使用**（瀏覽器不允許從硬碟開啟的網頁啟動背景程式） |
| 單一檔案版 | 執行 `python tools/build.py`，把 `dist/紙匣.html` 寄給別人 | 分享給不想下載整個專案的人；函式庫改從 CDN 載入，需要網路 |

## 工具

| 類別 | 工具 | 做什麼 |
|---|---|---|
| 整理頁面 | 合併 | 多份 PDF 或圖片接成一份，可只取部分頁面，**保留書籤**並為每份檔案加一個書籤；**雙面掃描交錯**把正面檔和反面檔排回正確順序 |
| | 拆分 | 依頁碼範圍、每 N 頁或每頁一份 |
| | 編輯 | 排序、旋轉、刪除、複製、插入頁面；加文字、簽名、標註；頁碼與頁首頁尾；**自動選取空白頁** |
| | 調整尺寸 | 統一成 A4 等紙張大小，或裁掉白邊 |
| 填寫與簽署 | 簽名 | 手寫或上傳簽名，套用到多頁，加上今天日期（西元或民國） |
| | 填表單 | 直接填寫 PDF 表單欄位，中文也看得到，可壓平 |
| 隱私與安全 | 遮蔽個資 | 框選或自動找出身分證號、電話、Email 等，匯出時**真正刪除**黑框下的內容；掃描檔也能找 |
| | 密碼 | 解除帳單、對帳單的密碼或列印限制；幫 PDF 加上 AES-256 密碼 |
| | 加浮水印 | 文字或圖片，置中、平鋪或四角 |
| 轉換 | 壓縮 | 保留文字或整頁轉圖片，可指定大小上限（例如 2 MB 以下） |
| | 圖片轉 PDF | JPG、PNG、HEIC 合成 PDF；翻拍的文件可以拉正、去陰影 |
| | PDF 轉圖片 | 每頁存成 JPG／PNG，或抽出文字 |
| | 文字辨識 | 掃描檔、照片辨識出繁中與英文，做成**可搜尋的 PDF** 或文字檔 |
| 比對 | 比較 | 兩個版本並排，刪掉的字標紅、新增的字標綠，逐處跳轉；也能**逐頁比對畫面**，找出圖片、印章、簽名的改變 |
| 證件 | 證件影印 | 證件正反面照片裁切拉正，依實際大小排在一張 A4，可壓上「僅供 ○○ 使用」 |
| | 證件照 | 大頭照裁成 2 吋、1 吋等規格，排滿 4×6 相紙或 A4 |
| 圖片 | 圖片工具 | 壓縮、縮小尺寸、轉換格式，可多張一起處理 |
| | 去浮水印 | 塗抹後自動補上背景 |

每個工具都有「用範例試試」，不用準備檔案就能看效果。完整說明見 [docs/features.md](docs/features.md)。

**找工具**：打開時是「全部工具」首頁，把檔案放進去會建議適合的工具；Ctrl+K 打字搜尋工具；下次開啟會回到上次用的工具。

**所有工具共通**：處理完先預覽、滿意再下載；結果可以「接著處理」直接交給下一個工具；Ctrl+V 貼上截圖或檔案；處理中可以取消；手機上長按拖曳排序。

## 隱私

- 檔案只在你的瀏覽器裡處理，紙匣沒有伺服器，不會上傳、不會記錄。
- 需要的函式庫都在 `lib/` 裡（線上版也是從同一個網站載入），第一次用到某個功能時才載入。唯一的外部連線是 Google Fonts 字型；離線時改用電腦內建字型，功能不受影響。
- 安裝成 App 或從線上版開啟過之後，紙匣會存在瀏覽器的快取裡，離線也能用；文字辨識、密碼、HEIC 要先在有網路時用過一次。
- 存在這台電腦瀏覽器裡的只有：簽名、證件影印的註記文字、日期格式、「完成後自動下載」的設定和上次用的工具；單一檔案版另外會快取文字辨識的語言資料，下次不用重新下載。

## 限制

- 用最新版 Chrome 或 Edge 開發與測試；其他瀏覽器大致可用，但沒有完整測試。
- 文字辨識認不出手寫字；照片模糊、歪斜或太暗時錯字會變多。
- 填表單不支援 XFA 動態表單。
- 比較的「比對畫面」是逐頁對照，中間插入一頁或文字重新排版後，後面都會被標成不同；這種情況用「比對文字」。
- 證件照不會自動去背或找臉，需要自己對準參考線；各機關規定以申請單位公告為準。

## 開發

沒有建置步驟、沒有套件要安裝：改完存檔、重新整理瀏覽器就看得到。

```powershell
python -m http.server 8000     # 本機執行，打開 http://localhost:8000
node tests/run.mjs             # 自動化測試（Node 22 以上、Chrome 或 Edge），約三分鐘
python tools/build.py          # 打包成單一檔案 dist/紙匣.html
```

推送到 `main` 後，GitHub Pages 約一分鐘就會更新線上版。新增工具、修正錯誤的做法和慣例見 [docs/development.md](docs/development.md)。

```
index.html      頁面：頁首、工具列、每個工具一個區塊
css/            樣式（含深色模式）
js/             程式，每個工具一個檔案，core.js 是共用基礎
lib/            第三方函式庫的本機副本（PDF、OCR、密碼、HEIC）
sw.js           離線使用；manifest.webmanifest、icons/ 讓它能安裝成 App
tests/          瀏覽器自動化測試
tools/          打包、產生圖示等腳本
docs/           說明文件
```
